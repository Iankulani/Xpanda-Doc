Install and run X Panda
from source in minutes.

X Panda is a Python-based automation tool distributed straight from its Git repository. This guide walks through cloning the source, setting up your environment, and connecting it to Discord, Telegram, and WhatsApp.

Start installing Browse commands
bash
$ git clone https://github.com/Iankulani/xpanda_v2.git
$ cd x-panda && python3 -m venv venv
$ python3 xpanda_v2.py
Before you begin

Requirements

X Panda runs anywhere Python and Git are available — Windows, macOS, or Linux.

01

Python 3.10+

Check with python3 --version. Install from python.org if it's missing.

02

Git

Needed to clone and later update the repository. Check with git --version.

03

pip

Comes bundled with Python and installs everything listed in requirements.txt.

Step by step

Installing X Panda via Git

Five steps take you from a clean machine to a running bot. Run each command from a terminal, in order.

1

Clone the repository

Download the source code to your machine.

terminal
# clone over HTTPS
git https://github.com/Iankulani/xpanda_v2.git
# move into the project folder
cd x-panda
2

Create a virtual environment

Keeps X Panda's dependencies isolated from the rest of your system.

terminal
python3 -m venv venv
# activate it
source venv/bin/activate      → macOS / Linux
venv\Scripts\activate         → Windows
3

Install dependencies

Pulls in every Python package X Panda needs to run.

terminal
pip install -r requirements.txt
4

Add your configuration

Copy the example environment file and fill in your bot tokens.

terminal
cp .env.example .env
# then open .env and add your tokens
5

Run X Panda

Starts the tool. Leave this terminal window open while it's running.

terminal
python3 xpanda_v2.py
Verify it works

Confirming X Panda is running

A healthy start prints a status line similar to the one below, and each connected platform will answer its help command.

xpanda.py output
[XPanda] loaded configuration from .env
[XPanda] Discord connection: online
[XPanda] Telegram connection: online
[XPanda] WhatsApp connection: online
[XPanda] ready — send !help, /help, or / to begin
Settings

Configuration reference

All settings live in the .env file created during installation. Restart X Panda after changing any value.

DISCORD_TOKEN
Bot token from the Discord Developer Portal.
TELEGRAM_TOKEN
Bot token issued by @BotFather on Telegram.
WHATSAPP_SESSION
Session identifier generated on first WhatsApp login.
LOG_LEVEL
Controls console verbosity: info, debug, or error.
PREFIX
Command prefix override for Discord, defaults to !.

Maintenance

Updating X Panda

Because X Panda runs from a Git clone, updating is a pull rather than a reinstall.

terminal
cd x-panda
git pull origin main
pip install -r requirements.txt --upgrade
python3 xpanda.py
Common issues

Troubleshooting

"git: command not found"
Git isn't installed yet. Install it from git-scm.com, then reopen your terminal.
Bot shows offline
Double-check the matching token in .env and confirm the bot is invited to the server or chat.
ModuleNotFoundError
The virtual environment isn't activated, or a package failed to install — rerun pip install -r requirements.txt.
Commands don't respond
Confirm the prefix matches your platform: ! on Discord, / on Telegram and WhatsApp.
